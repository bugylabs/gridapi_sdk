# Code of conduct

BugyLabs expects respectful, constructive participation in this project.

## Our standards

- Be respectful of different backgrounds, experience levels and viewpoints.
- Give and accept technical feedback without personal attacks.
- Focus on the public SDK contract and reproducibility when reporting problems.
- Never post API keys, customer data or private backend details in issues or PRs.

## Unacceptable behavior

Harassment, discrimination, threats, publishing someone else's private
information, and deliberate attempts to disrupt the project are not tolerated.

## Reporting

Report unacceptable behavior privately to <security@gridapi.in> with enough
context to act; do not include sensitive data. Reports are handled confidentially.
Maintainers may remove content or restrict participation when needed.

This code of conduct applies to all project spaces and to individuals
representing the project in public.
