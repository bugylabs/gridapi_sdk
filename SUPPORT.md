# Support

- Questions and bugs: <https://github.com/bugylabs/gridapi-sdk/issues>. Include
  SDK language and version, runtime version, the operation attempted, and a
  redacted request/response. Never paste an API key or project data.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md); do not open a
  public issue.
- Commercial licensing: contact BugyLabs through the repository owner. The
  [license](LICENSE) prohibits commercial use without a separate written
  agreement.
- The API contract is published at [openapi/openapi.yaml](openapi/openapi.yaml);
  the dashboard documentation in `gridapi_client` is the human-facing source.
- Support is best-effort; no SLA is implied by this repository.
